# 知课 · Video Course Assistant

这个文件记录当前实现和运行方式。原始 README.md 保留用户的需求，不由程序修改。

知课把课堂录音、视频、字幕和讲义放在同一个工作台：分章回看、提取老师的通知、查原文、选段提问，再按需要连接语音和视觉模型。

## 快速启动

推荐 Node.js 24 LTS；最低 Node.js 22.12。FFmpeg 和 ffprobe 用于音频切片、读取媒体时长和提取视频帧。只导入文字稿时不需要模型账号。

```sh
npm ci
npm run dev
```

开发界面在本机 5173 端口，API 在 3001 端口；Vite 代理 `/api` 和 `/media`。生产模式先构建，再运行：

```sh
npm run build
npm start
```

生产服务器同时提供网页和 API，默认只监听 `127.0.0.1:3001`。Linux/macOS 也可以执行 `./scripts/start.sh`；它以前台方式运行，按 Ctrl-C 停止。确需让其他机器访问时，可设置 `HOST=0.0.0.0`；这是本地单用户应用，没有登录和访问控制，不适合直接暴露到公网。

可用环境变量：

| 名称 | 用途 |
| --- | --- |
| `PORT` | API 和生产网页端口，默认 `3001` |
| `HOST` | 监听地址，默认 `127.0.0.1` |
| `DATA_DIR` | 本地课程、上传文件和模型配置目录，默认仓库下的 `data/` |

### Windows 双击运行

1. 首次运行 `install.bat`：检查 Node.js 与 FFmpeg，安装 npm 锁定依赖并构建网页。缺少系统工具时，会询问是否通过 Windows Package Manager 安装 `OpenJS.NodeJS.LTS` 或 `Gyan.FFmpeg`；未经确认不会安装。也可自行安装后重新运行。完成后会自动在后台启动应用并打开浏览器。
2. 双击 `start.bat`：在后台启动服务，等健康检查通过后打开浏览器，不需要保留命令行窗口。
3. 双击 `stop.bat`：只停止这份仓库启动、且 PID 与启动时间仍匹配的 Node 进程，不会结束其他 Node 程序。

日志在 `data/logs/server.log` 和 `data/logs/server-error.log`。端口被其他服务占用时会报错，不会强制终止它。更新代码或依赖后，先停止应用，再重新运行安装与启动脚本。脚本通过 PowerShell 执行本仓库自己的启动文件；首次安装依赖需要联网。Windows 脚本尚未在实际 Windows 机器上验证。

## 一次完整的使用流程

1. 导入本地音视频，可以同时加入文字稿、字幕或讲义；也可以先读文字稿，之后补上录音。
2. 查看章节、摘要和原文。点击字幕或章节可跳到对应位置；选择起止范围后，再对该段提问或运行处理。
3. 在重点区域填写自己的关键词。老师的作业通知、考试、下节课安排也是重点，不局限于学科知识点。演示以“作业、大作业、期末、开卷、下节课、提醒”为例；可以随时修改。
4. 未连接模型时，应用能做原文关键词匹配和原文检索，结果会注明来源。这种模式不会伪装成语音识别、翻译或模型推理。
5. 需要双语字幕、语音转录或模型答疑时，在设置中连接兼容接口。导出 Markdown 笔记、SRT/VTT 字幕或 JSON，保存在自己的机器上。

### 文件和时间轴

支持 MP3、WAV、M4A、OGG、MP4、WEBM、MOV，以及 MD、TXT、SRT、VTT、PDF 和 PPTX。PPTX 通过跨平台 ZIP 解析提取文字，不需要安装解压工具；仅含图片的幻灯片没有可提取文字。旧版二进制 PPT 不支持，可先导出 PDF。扫描版 PDF 需要先 OCR，当前不把图片扫描件当作已识别文字。上传每次最多 8 个文件，单文件上限 1 GiB，文字类文件上限 10 MiB；实际部署的反向代理可能另有限制。

**没有时间码的文字稿只能估算时间。** 根据字数分配的起止点会标为估算，不能当作录音中的精确位置；导入 SRT/VTT 或成功运行带时间码的转录后才能得到实际字幕时间。上传后端能解码的媒体后，会读取时长以辅助定位。音频不会显示不存在的视频画面。

导入文档会保留原文。模型校对稿保存在独立字段，不覆盖原始识别文本；翻译未生成时会显示相应状态，不用占位中文冒充第二语言。

## 连接模型

设置中填写兼容 OpenAI 的接口地址、文本/视觉模型和语音模型。API 密钥只交给本地服务，读取设置的响应不会返回密钥值。配置保存在 `DATA_DIR/provider.json`，采用用户读写权限（Windows 文件权限依操作系统而定），**文件中的密钥是明文，备份和分享 data 目录前必须处理**。不要提交 `.env`、课程文件或 data 目录。

可以使用自行申请的兼容服务，也可使用本机 Ollama 等服务的 OpenAI 兼容地址（例如 `http://127.0.0.1:11434/v1`）。模型名称必须与服务中真实可用的名称一致；Ollama 的文本接口不意味着它同时支持语音转录。应用不内置第三方密钥，也不承诺永久免费的公共模型额度。是否收费、是否支持视觉或推理强度由所用服务决定。

上传到兼容模型服务的数据会离开本机。只有用户主动运行相应功能时，才发送所选课堂材料；使用视觉功能时还会提取并发送视频帧。课堂文档只作为待分析资料，不应当作系统指令执行。

## 验证与开发

```sh
npm run typecheck
npm test
npm run build
```

项目结构：

- `src/`：React 界面和前后端共享数据类型。
- `server/`：课程存储、导入解析、导出、后台处理任务和模型接口。
- `examples/`：可随应用启动的示例材料；私人上传文件放在忽略的 data 目录中。
- `tests/`：解析、关键词匹配、时间范围和模型响应等核心行为测试。
- `scripts/`：本地启动脚本。

当前界面和接口属于本地单用户版本，后台任务运行在当前服务进程中；停止进程会中断尚未完成的处理。模型处理仍取决于可用的服务、密钥和额度。只读取文字稿的演示不能证明录音已转录，也不能证明未上传的幻灯片已被视觉校对。
