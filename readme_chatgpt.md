# 知课 · Video Course Assistant

这个文件记录当前实现和运行方式。原始 README.md 保留用户的需求，不由程序修改。

知课把课堂录音、视频、字幕和讲义放在同一个工作台：分章回看、提取老师的通知、查原文、选段提问，再按需要连接语音和视觉模型。

## 快速启动

推荐 Node.js 24 LTS；最低 Node.js 22.12。FFmpeg 和 ffprobe 用于音频切片、读取媒体时长和提取视频帧。只导入文字稿时不需要模型账号。

```sh
npm ci
npm run dev
```

开发界面在本机 5173 端口，API 在 3001 端口；Vite 代理 `/api` 和 `/media`。生产模式先构建，再运行：

```sh
npm run build
npm start
```

生产服务器同时提供网页和 API，默认只监听 `127.0.0.1:3001`。Linux/macOS 也可以执行 `./scripts/start.sh`；它以前台方式运行，按 Ctrl-C 停止。确需让其他机器访问时，可设置 `HOST=0.0.0.0`；这是本地单用户应用，没有登录和访问控制，不适合直接暴露到公网。

可用环境变量：

| 名称 | 用途 |
| --- | --- |
| `PORT` | API 和生产网页端口，默认 `3001` |
| `HOST` | 监听地址，默认 `127.0.0.1` |
| `DATA_DIR` | 本地课程、上传文件和模型配置目录，默认仓库下的 `data/` |

### 一键准备本机免费模型

Windows 首次双击 `install.bat`。安装在后台运行，浏览器显示实时进度；可以关闭进度页或命令行窗口，不会因此终止模型下载。缺少 Node.js LTS、Python 3.12、FFmpeg 时，脚本通过 Windows Package Manager 安装；系统安装器可能弹出授权窗口。之后自动安装锁定的应用依赖、构建网页，再准备以下本地模型：

- SenseVoice：第一轮语音识别。
- Paraformer：独立语音复核。
- Whisper small：对关键疑点进行额外复听。
- 本地中文文本模型：整理文档、解释术语和课堂答疑；由模型安装器校验下载内容，应用自动连接本机服务。

视频画面分析需要选择支持图像输入的模型；语音和文本准备完成后，视觉能力仍按实际连接状态显示。

模型安装会下载较大的文件，需要首次联网。每个阶段都分别显示完成或失败，缺少的辅助模型不会显示为已安装，也不会把待复核内容标为正确。已校验的下载会缓存，失败后再次双击 `install.bat` 可重试。默认安装路径为项目的 `data/`，不会清空课程资料或已有模型服务配置。

准备完毕后自动在后台启动应用并打开网页。以后双击 `start.bat` 即可；如果依赖或构建缺失，它会转入后台安装。双击 `stop.bat` 只停止这份仓库记录且进程身份仍匹配的应用，不结束其他 Node 程序，也不停止正在进行的模型下载。重新安装前，应先完成正在处理的课程，再停止应用。

进度文件为 `data/setup/status.html` 和 `status.json`；日志在 `data/logs/setup.log`、`setup-bootstrap.log`、`setup-bootstrap-error.log`。应用日志为 `server.log` 和 `server-error.log`。端口冲突时会报错，不会强制结束占用端口的其他服务。Windows 脚本已作静态检查，尚未在实际 Windows 机器上运行验证。

Linux/macOS 可执行 `./scripts/install.sh`，它也在后台准备环境并启动应用。先安装 Node.js 22.12+、Python 3.11+ 和 FFmpeg；系统工具不会由该脚本擅自修改。进度同样保存在 `data/setup/status.html`。如需在终端查看完整日志，可运行 `./scripts/install.sh --foreground`。已安装后的后台启动为 `./scripts/start.sh --background`，停止为 `./scripts/stop.sh`；不带参数的 `start.sh` 保留前台运行方式，适合开发和服务管理器。

只核验当前安装、不重新安装依赖或下载模型：

```sh
python3 scripts/setup-all.py --check-only
```

低配置机器可加 `--skip-text-model` 或 `--skip-critical-model`，状态页会明确显示相应能力未安装。底层安装器均支持重复执行，模型文件和二进制按官方发布摘要校验后使用。

## 一次完整的使用流程

1. 导入本地音视频，可以同时加入文字稿、字幕或讲义；也可以先读文字稿，之后补上录音。
2. 查看章节、摘要和原文。资料卡可打开保留的原始文字稿。点击字幕或章节可跳到对应位置；视频附带原生字幕轨，可在全屏播放器中显示；勾选字幕生成范围后，可以手动编辑起止时间，再对该段提问或运行处理。
3. 在重点区域填写自己的关键词。老师的作业通知、考试、下节课安排也是重点，不局限于学科知识点。演示以“作业、大作业、期末、开卷、下节课、提醒”为例；可以随时修改。
4. 未连接模型时，应用能做原文关键词匹配和原文检索，结果会注明来源。这种模式不会伪装成语音识别、翻译或模型推理。
5. 使用整堂课处理流程，由语音模型协作识别、生成文档并标出待审查项。可从审查条目跳回原录音，核对数字、否定词和术语。处理和审查状态分别保存；仍有疑点时不会显示为整课审查通过。需要其他服务时也可在设置中连接兼容接口。导出 Markdown 笔记、SRT/VTT 字幕或 JSON，保存在自己的机器上。

### 文件和时间轴

支持 MP3、WAV、M4A、OGG、MP4、WEBM、MOV，以及 MD、TXT、SRT、VTT、PDF 和 PPTX。PPTX 通过跨平台 ZIP 解析提取文字，不需要安装解压工具；仅含图片的幻灯片没有可提取文字。旧版二进制 PPT 不支持，可先导出 PDF。扫描版 PDF 需要先 OCR，当前不把图片扫描件当作已识别文字。上传每次最多 8 个文件，单文件上限 1 GiB，文字类文件上限 10 MiB；实际部署的反向代理可能另有限制。

**没有时间码的文字稿只能估算时间。** 根据字数分配的起止点会标为估算，不能当作录音中的精确位置；导入 SRT/VTT 或成功运行带时间码的转录后才能得到实际字幕时间。上传后端能解码的媒体后，会读取时长以辅助定位。音频不会显示不存在的视频画面。

导入文档会保留原文。模型校对稿保存在独立字段，不覆盖原始识别文本；翻译未生成时会显示相应状态，不用占位中文冒充第二语言。

示例材料节选自本次计算机绘图文字稿，已去除领取作业的学生名单。用户提供的完整版文字稿只导入本机忽略的 data 目录，不作为公开示例提交。仓库中的 `icourse_2026-11-02_9beea023.mp3` 是用户提供的原始课程录音，实际识别和审查产物与来源记录保存在本机 data 目录。小型样本测试不能替代对整堂录音的审查。


## 无需 API Key 的本地录音识别

现已提供真正的本机中文语音识别（SenseVoice int8 + Silero VAD），不是用参考文字稿填充识别结果。一键安装会自动完成准备；也可单独在项目目录运行：

```sh
python3 scripts/setup-local-asr.py
```

安装脚本创建 `data/local-asr/venv` 并从官方发布下载、校验模型。准备好后，界面的“本地转录”直接处理上传的录音；不需要配置文本模型或购买语音 API。已安装本地文本模型时，应用可自动使用本机接口；也可按偏好设置选择其他兼容接口。可用 `LOCAL_ASR_PYTHON` 和 `LOCAL_ASR_MODEL_DIR` 指定已有环境与模型目录。

转录前的原稿和旧字幕均保留，识别记录包含实际音频的 SHA-256、模型名称和处理时间。时间标记来自实际语音活动分段，**不是逐字强制对齐**。第一次应取消估算时间上的选段，完整转录后再做精准选段。模型仍可能识错专有名词，不会用用户给的参考稿偷偷替换识别输出。

更详细的 CLI、模型来源和本机验证方法见 [本地识别说明](scripts/local-asr.md)。识别器已用真实中文语音运行验证；对某份完整录音是否处理完、是否仍有待审查项，应以该课程的工作流和审查记录为准。

## 连接模型

设置中填写兼容 OpenAI 的接口地址、文本/视觉模型和语音模型。保存连接设置后，可读取服务返回的可用模型列表，在模型输入框中选择；服务未提供模型列表时仍可手动输入名称。API 密钥只交给本地服务，读取设置的响应不会返回密钥值。配置保存在 `DATA_DIR/provider.json`，采用用户读写权限（Windows 文件权限依操作系统而定），**文件中的密钥是明文，备份和分享 data 目录前必须处理**。不要提交 `.env`、课程文件或 data 目录。

一键准备会安装并自动连接可用的本机文本服务；已有的用户自定义接口配置会保留。还可以使用自行申请的兼容服务，或本机 Ollama 等服务的 OpenAI 兼容地址（例如 `http://127.0.0.1:11434/v1`）。模型名称必须与服务中真实可用的名称一致；Ollama 的文本接口不意味着它同时支持语音转录。应用不内置第三方密钥，也不承诺永久免费的公共模型额度。是否收费、是否支持视觉或推理强度由所用服务决定。

校对会先让语音模型重新识别所选录音，再由文本模型对照原文字稿和讲义核对术语、明显错字。纯录音可运行这条流程；视频还会加入采样画面。文本模型接收的是语音识别结果，不会声称它直接听过音频；采样帧也不代表逐帧看完视频。估算时间的文字稿不能保证与重新识别的音频精确对齐，不确定时应保留原文。

上传到兼容模型服务的数据会离开本机。只有用户主动运行相应功能时，才发送所选课堂材料；使用视觉功能时还会提取并发送视频帧。课堂文档只作为待分析资料，不应当作系统指令执行。

## 验证与开发

```sh
npm run typecheck
npm test
npm run build
npx playwright test
```

浏览器测试会在独立端口和临时数据目录中启动服务，覆盖导入、关键词重点、原文答疑、选段和导出等界面流程。默认使用 `/usr/bin/chromium`（存在时），也可以设置 `CHROMIUM_PATH` 指向本机 Chromium；没有本机浏览器时先运行 `npx playwright install chromium` 下载 Playwright 浏览器。可用 `E2E_PORT` 修改测试端口。

项目结构：

- `src/`：React 界面和前后端共享数据类型。
- `server/`：课程存储、导入解析、导出、后台处理任务和模型接口。
- `examples/`：可随应用启动的示例材料；私人上传文件放在忽略的 data 目录中。
- `tests/`：解析、关键词匹配、时间范围和模型响应等核心行为测试。
- `scripts/`：本地启动脚本。

当前界面和接口属于本地单用户版本，后台任务运行在当前服务进程中；停止进程会中断尚未完成的处理。模型处理仍取决于可用的服务、密钥和额度。只读取文字稿的演示不能证明录音已转录，也不能证明未上传的幻灯片已被视觉校对。
